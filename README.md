A one-line roast for the [make.fun](https://make.fun/bounty/u-carbon-forge-midnight-fridge-roast-fc5d44a7) bounty **Midnight Fridge Roast**: a smart fridge that locks itself at midnight gets roasted like a nightclub bouncer guarding nothing but last Tuesday's leftover pizza.

`main.ts` (Node 22) writes the single entry line to `/output/entry.txt`:

> My smart fridge locks at midnight like a nightclub bouncer — mate, the only VIP in there is last Tuesday's leftover pizza.

Run it with:

```sh
node main.ts
```
